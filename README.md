# conrad

The public page for **Conrad**, a private single-user Gmail on-call assistant.

Two static pages served by GitHub Pages at `dentalize.cz`. They exist because Google requires a
homepage and a privacy policy URL before an OAuth app may leave "Testing" status — and a testing-status
app expires its refresh token every seven days, which for an always-on watcher means breaking weekly.

- `index.html` — what Conrad is
- `privacy.html` — what it accesses and what it shares
- `CNAME` — the custom domain for GitHub Pages

The assistant itself lives elsewhere and is not public.
